Ledger Ed25519 key derivation using Cardano-style BIP32-Ed25519

This implements the same key derivation used by Ledger hardware wallets for Polkadot and other Substrate-based chains.

Key derivation path: m/44’/slip0044’/account’/change’/address’ For Polkadot: m/44’/354’/0’/0’/0’

Note: Ledger uses Cardano-style BIP32-Ed25519, NOT SLIP-10. The difference is in the master key generation which iterates until a valid key is found.
