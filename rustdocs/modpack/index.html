modpack — release tooling for signed protocol-module packages.

Deliberately three separate commands, because a release happens on three separate machines and no one of them ever holds two release keys:

prepare (build host) module + changelog -> the bytes to be signed [scan] (signing devices) each holder approves and returns 64 bytes assemble (build host) prefix + 2 signatures + payload -> .zmod

module_host::manifest::build_package does all of that in one call and is for tests only: it needs every key in one process, which is precisely what 2-of-3 custody exists to prevent.
